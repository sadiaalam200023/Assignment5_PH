This project's name is DevStack.

It shows the language and library stacks that are commonly used to develop websites. It can help a developer to customize their own stack.

Stack used to make this website: React, Vite, TypeScript, Tailwind CSS, DaisyUI

Some features of this website - You can explore the options best suited for your website or application as they are rated and categorized, once you add your stack using the add stack button it will show your customized stack. You can add or remove from it. 




#1 JSX is JavaScript XML used to render html components with javascript.
#2 props are information that are given to components to make them get certain features while state is information a component remembers and can change later.
#3 useState is kind of like an internal memory that helps to remember the state that can be changed
#4 UseEffect is used to act as a buffer after React renders the components such as when json data is fetched and needs to work with the components present.
#5  unique key helps to differentiate and identify each item and update them accordingly 
#6 conditional rendering means a UI will be showed only if a specific condition is met..such as if there are no items added to stack then empty stack will be shown.
#7 parent sends data to child using a prop. Parent can give child access to call back functions via props that they can use to call the parent.
